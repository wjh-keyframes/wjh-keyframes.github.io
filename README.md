# Project page: What Just Happened?

Static project page, adapted from the [Nerfies](https://github.com/nerfies/nerfies.github.io) template
(CC BY-SA 4.0; the footer keeps the required link back). Figures are cropped from the TMLR submission.

Open `index.html` in a browser to preview. To publish with GitHub Pages: push this folder to a repository,
then Settings -> Pages -> Deploy from a branch -> `main` / root.

Before publishing, fill the TODOs in `index.html`: authors, Paper / arXiv links, BibTeX.
